Corex Linux

A Lightweight, Windows-Friendly Linux Distribution

Corex Linux is a modern, efficient Linux distribution designed to breathe new life into older hardware and provide a familiar experience for users transitioning from Windows. Available in both Debian-based (stability) and Arch-based (cutting-edge) editions.

🧰 Windows Administration Tools — Made for Linux

One of the core goals of Corex Linux is to bring the power and familiarity of Windows administrative tools to the Linux ecosystem.

Task Manager → htop, bpytop, custom GUI monitor
Control Panel → Centralized settings manager
Event Viewer → journalctl, Logwatch frontend
Group Policy Editor → PolicyKit & DConf tools
Services Manager → Systemd graphical interface
Disk Management → GParted, Disks utility
